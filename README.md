# 🍕 Pizza Sales Analysis using MySQL

## 📌 Project Overview

This project analyzes a pizza restaurant's sales data using **MySQL** to uncover valuable business insights. The analysis focuses on customer ordering patterns, revenue generation, product performance, and sales trends by writing SQL queries on a relational database.

The project demonstrates practical SQL skills commonly required for Data Analyst roles, including joins, aggregate functions, subqueries, Common Table Expressions (CTEs), and window functions.

---

## 🎯 Business Objectives

- Analyze overall sales performance
- Identify top-selling pizzas
- Calculate total revenue
- Understand customer ordering patterns
- Determine peak business hours
- Analyze category-wise revenue contribution
- Identify best-performing pizza sizes and categories

## 📂 Dataset

The dataset consists of four relational tables.

| Table | Description |
|--------|-------------|
| orders | Customer order information |
| order_details | Quantity of pizzas ordered |
| pizzas | Pizza size and price |
| pizza_types | Pizza name, category and ingredients |

## 📊 Business Questions Solved

- Highest-priced pizza
- Most common pizza size
- Top 5 most ordered pizza types

### Intermediate Analysis

- Quantity sold by category
- Orders by hour

### Advanced Analysis

- Percentage contribution of each category to total revenue
